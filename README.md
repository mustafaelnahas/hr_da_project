# HR Analytics & Employee Performance — Graduation Project

## Scenario
A medium-sized company wants to understand differences in employee performance, satisfaction, salary, training, workload, and absence across departments. The dataset is synthetic and for teaching only.

## Files
- `hr_employee_raw.csv`: intentionally messy employee dataset.
- `app.py`: interactive Streamlit dashboard.
- `analysis_starter.py`: guided examples for NumPy, Pandas, Matplotlib, Seaborn, and Plotly.
- `trainer_guide.pdf`: challenge-based two-hour trainer guide with hints and expected reasoning.
- `requirements.txt`: Python dependencies.

## Run
`pip install -r requirements.txt`
`streamlit run app.py`

Keep `hr_employee_raw.csv` in the same folder as `app.py`.

## Important
HR data is sensitive in real settings. Use this synthetic dataset only for teaching. Do not use correlations or group averages to make individual employment decisions.
